# 17Lands ATA-tax analysis

How much of a card's 17Lands win rate is real strength versus inflation from
being picked late? A card taken later was acquired more cheaply, so the deck
around it is better — an "ATA tax" on the printed stats. This project measures
it across four formats (SOS, FIN, TLA, Arena Powered Cube) and, in the process,
catalogs the confounders that make 17Lands win rates hard to read.

**One-line answer:** the tax is real, small, front-loaded, and lives in deck
quality (GNS WR) — about **+0.1–0.15pp of GIH per taken-at pick**. The log-based
as-picked design measures it cleanly; the weekly re-pricing panel does not (it
mostly measures the archetype underneath the card).

## The library (`lib17`)

Reusable 17Lands-analysis primitives; everything reads the local cache in
`data/`, nothing hits the network except `fetch.*`.

| module | what it provides |
|---|---|
| `fetch` | 17Lands `card_ratings` API (cached, rate-limited), public S3 logs, Scryfall bulk |
| `data` | format registry, log→parquet prep, per-card aggregates (`card_stats`), as-picked cells (`aspicked`), weekly stat tables |
| `metrics` | metric definitions + bias notes; constants `KAPPA` (ALSA→ATA = 1.546), `BOOST_PER_PICK` |
| `analysis` | cross-sectional designs: `aspicked_slopes`, `within_card`, robustness (pod/rank/week FE), `weekly_panel`, `kappa` |
| `weekly` | weekly-panel + archetype machinery: `weekly_panel`, `find_movers`, `residualize`, `arch_baseline`, `card_by_archetype`, `season_split` (GIH = GNS + IIH) |
| `overview` | general format-context primitives (whole-format and weekly): `top_cards`, `top_cards_week`, `archetype_summary`, `archetype_trends`, `biggest_movers` |
| `decks` | deck-composition WR primitives (which cards/packages win together): `wr`, `cooccurrence_wr`, `count_bucket_wr`, `count_grid_wr` (2-D density), `synergy_matrix` |
| `htmlfmt` | shared HTML/figure styling |

```python
from lib17 import overview, weekly, analysis, data

```

## Headline findings (full catalog in `NOTES.md`)

- **As-picked design** (same card, different pick, card FE): tax ≈ +0.13 GIH /
  +0.15 GNS per taken-at pick; **largest slope on GNS** → it's the surrounding
  deck. Front-loaded; maindeck rate falls ~4pp/pick. Robust to pod/rank/week FE.
- **The weekly panel overstates it** and is unstable across metric/units/subset.
  Netting each card's WR against its own archetype's weekly WR collapses the
  slope — it was reading the archetype's seasonal arc, not the card.
- **GIH = GNS + IIH**: GNS is deck context (archetype, build, pilot); IIH is the
  card's own in-hand value, deck-cancelled. **26/30 biggest movers are
  deck-driven** (ΔGNS), only 4 card re-evaluations (ΔIIH).
- **Metric biases handled**: GIH long-game lean; OH mana-value penalty; GNS
  short-game lean (length-reweighted); Power-dominated cost buckets (cube);
  build-around deckbuilding tax; ALSA≠ATA (÷1.546); deployment survivorship.
